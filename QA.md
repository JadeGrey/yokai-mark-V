# Yokai Mark V — Manual QA Checklist

This document details the 25 manual verification procedures to validate Yokai Mark V in Discord alongside automated unit tests.

---

## QA Execution Matrix

| # | Test Case | Target State / Expected Behavior | Verification Steps | Status |
|---|---|---|---|---|
| **1** | **Fresh Start & Idle Presence** | • Presence: `idle`<br>• Activity: `Watching for plant`<br>• No audio connections or active timers. | Start the bot (`.\run.ps1`). Check the bot's user profile in Discord member list. | `Pending Owner Run` |
| **2** | **VC Join & DAVE Audio** | • Bot joins voice channel.<br>• Discord DAVE E2EE voice handshake succeeds.<br>• Audio plays clearly without stutter.<br>• Presence updates to `online`. | 1. Join a voice channel.<br>2. Run `/play query: https://www.youtube.com/watch?v=dQw4w9WgXcQ`<br>3. Verify audio stream and bot presence is Online. | `Pending Owner Run` |
| **3** | **Input Resolution Matrix** | • Free-text search resolves top track.<br>• YouTube playlist queues up to cap with summary embed.<br>• Spotify track matches YouTube audio.<br>• Spotify album/playlist queues lazily as pending matches. | 1. `/play query: lofi hip hop`<br>2. `/play query: <youtube playlist url>`<br>3. `/play query: <spotify track url>`<br>4. `/play query: <spotify album or playlist url>` | `Pending Owner Run` |
| **4** | **Playback & Queue Controls** | • `/pause` halts audio; `/resume` continues at exact timestamp.<br>• `/skip` advances queue immediately.<br>• `/loop mode: track` loops current; `/loop mode: queue` cycles queue; `/loop mode: off` disables.<br>• `/shuffle` randomizes upcoming tracks.<br>• `/remove position: N` removes track.<br>• `/clear` clears queue.<br>• `/volume level: 50` updates volume. | Run each command in sequence while tracks are queued and active. Verify responses and queue state via `/queue`. | `Pending Owner Run` |
| **5** | **Recommendations (`/recommend`)** | • Returns 8 non-duplicate YouTube Music radio tracks in themed embed.<br>• "Queue them all" button enqueues all tracks.<br>• Button disables after press (single use).<br>• Concurrency lock prevents double-press. | 1. While a track is playing, run `/recommend`.<br>2. Click **Queue them all**.<br>3. Confirm tracks append to queue and button disables. | `Pending Owner Run` |
| **6** | **Empty Channel Auto-Disconnect** | • Bot detects when all human users leave the VC.<br>• Auto-disconnect timer triggers after 120s.<br>• Bot leaves VC; presence returns to `idle`. | 1. Join VC with bot playing.<br>2. Disconnect from VC, leaving bot alone.<br>3. Wait 120 seconds. Verify bot disconnects and presence becomes Idle. | `Pending Owner Run` |
| **7** | **Voice Kick & Move Handling** | • When kicked from VC, bot cleans up player state.<br>• Stop timers, clear queue, return presence to `idle`.<br>• When moved to another channel, player tracks move. | 1. Right-click bot in VC -> Disconnect (kick).<br>2. Verify bot logs disconnect and returns presence to Idle.<br>3. Confirm next `/play` works cleanly. | `Pending Owner Run` |
| **8** | **Network Disruption Recovery** | • If network drops briefly, FFmpeg reconnects (`-reconnect 1`).<br>• On permanent drop, player records event and skips or halts cleanly without crashing. | 1. During active playback, toggle internet connection off for 3 seconds, then back on.<br>2. Verify playback recovers or skips gracefully. | `Pending Owner Run` |
| **9** | **Utility & Diagnostics Suite** | • `/ping`: Displays Gateway, REST, Database, Voice, and Resolver latencies.<br>• `/usage [period]`: Shows top operators and commands with mentions.<br>• `/about`: Displays versions, uptime, OS, and Ubisoft disclaimer.<br>• `/admin diag`: Rejects non-admins with error embed; displays ephemeral telemetry + Update yt-dlp button for the owner or an admin. | 1. Run `/ping`, `/usage period: 7d`, and `/about`.<br>2. Run `/admin diag` as the configured bot owner.<br>3. Have another user run `/admin diag` and verify refusal. | `Pending Owner Run` |
| **10** | **Process Supervision & Auto-Restart** | • Killing python process triggers `run.ps1` cooldown.<br>• Bot restarts after 5 seconds automatically. | 1. Launch Yokai using `.\run.ps1`.<br>2. In Task Manager or PowerShell, kill the `python.exe` process.<br>3. Verify `run.ps1` captures crash and restarts Yokai in 5 seconds. | `Pending Owner Run` |
| **11** | **Cold `/play` Latency** | • Audio starts in about 3 s or less after `/play` with a song name.<br>• The bot shows as joined in the voice channel before (or as) the audio starts, not seconds after the reply. | 1. Join a voice channel.<br>2. Run `/play query: <song name>` for a song not played recently.<br>3. Note the time from pressing Enter until audio is heard. | `Pending Owner Run` |
| **12** | **Gapless Track Change** | • No audible gap when the first track ends and the second begins. | 1. `/play` two tracks (short ones help).<br>2. Listen at the end of the first track.<br>3. Confirm the second starts with no audible gap. | `Pending Owner Run` |
| **13** | **Skip During Slow Load** | • `/skip` responds immediately even while the track is still loading.<br>• Bot moves on to the next track or goes idle without hanging. | 1. `/play` a track not played before.<br>2. Press `/skip` while Discord still shows "thinking" / the track is loading.<br>3. Verify the bot recovers and `/queue` is consistent. | `Pending Owner Run` |
| **14** | **Rapid Double Skip** | • Two quick `/skip` commands advance exactly two tracks.<br>• No track is skipped twice or replayed. | 1. Queue three tracks.<br>2. Run `/skip` twice in quick succession.<br>3. Verify the third track plays and `/queue` is correct. | `Pending Owner Run` |
| **15** | **Stop While Looping** | • `/stop` clears the queue and the looped track does not return. | 1. `/loop mode: track` while a track plays.<br>2. Run `/stop`.<br>3. Run `/play` with a new track and confirm the old one does not return. | `Pending Owner Run` |
| **16** | **Wi-Fi Drop Mid-Track** | • Playback resumes, or skips cleanly, after a 5 s network loss.<br>• No crash and no silent hang. | 1. During playback, disconnect Wi-Fi for 5 seconds, then reconnect.<br>2. Verify audio resumes (or the bot skips to the next track cleanly). | `Pending Owner Run` |
| **17** | **Buffer Folder Deleted Mid-Play** | • Playback continues when `data/cache` contents are deleted during a track. | 1. Play a track with another queued so the buffer fills.<br>2. Delete the contents of `data/cache` while it plays.<br>3. Verify playback continues and the next track still plays. | `Pending Owner Run` |
| **18** | **Now-Playing Card (Idle `/play`)** | • The card title is the track title and is a clickable link to its YouTube page.<br>• An artist line and a progress bar are shown: a fresh bar at position 0 is `●` plus `─` only; `━` fills in as the track progresses.<br>• Inline fields: Duration, Requested by, Source.<br>• Exactly one emoji on the card. | 1. While idle in a voice channel, run `/play query: <song name>`.<br>2. Click the title; confirm it opens the track.<br>3. Check the artist line, the bar, the three fields and the single emoji. | `Pending Owner Run` |
| **19** | **Queued Card** | • Title `Queued` with a linked, bold track name.<br>• Position and Plays in are shown; Plays in is close to the real wait.<br>• Duration, Requested by and Source fields are present. | 1. While a track plays, run `/play query: <another song>`.<br>2. Compare Position with `/queue`.<br>3. Time how long until it actually starts and compare with Plays in. | `Pending Owner Run` |
| **20** | **Long Queue Page** | • Header shows Now playing (only while a track plays), total runtime (only when track durations are known) and loop state.<br>• Ten compact numbered lines per page.<br>• Prev/Next buttons page correctly. | 1. Queue more than 10 tracks.<br>2. Run `/queue`.<br>3. Check the header and the ten lines, then press Next and Prev. | `Pending Owner Run` |
| **21** | **Empty Queue** | • `/queue` on an empty queue shows a clear "queue is empty" embed with the quip, not a broken list.<br>• If a track is playing, the header still shows Now playing above "The queue is empty." | 1. Run `/clear` (or start fresh).<br>2. Run `/queue`.<br>3. Verify the empty-state embed. | `Pending Owner Run` |
| **22** | **Import Summary** | • Loaded and Queued fields are shown; the Now playing field appears only when the bot was idle when the playlist was added.<br>• A partial import shows "loaded N of M".<br>• If the queue limit cuts the import short, a "Queue limit reached" line says how many tracks fit. | 1. Run `/play query: <spotify playlist url>`.<br>2. Verify the summary embed fields and counts against `/queue`. | `Pending Owner Run` |
| **23** | **Error Embed Shape** | • Specific title (never a generic "Error").<br>• Plain-text explanation and a separate `Try` field.<br>• The quip appears only in the footer; one emoji in the title.<br>• The unsupported-link error is ephemeral (only you see it). Errors after a search has started (for example "Nothing found") are visible to the channel, because Discord fixes a deferred reply's visibility when it is deferred. | 1. Run `/play query: <unsupported link>`.<br>2. Leave the voice channel and run `/play query: test`.<br>3. Check each error embed for the shape above. | `Pending Owner Run` |
| **24** | **Markdown Escaping** | • A track title containing markdown or a bracketed link renders as plain text and is never a live link. | 1. Search for or play a track whose title includes `[text](url)`, `*`, or `_`.<br>2. Check the now-playing, queued and queue embeds: the text is literal and nothing extra is clickable. | `Pending Owner Run` |
| **25** | **Grids and Status Colors** | • `/ping`, `/about` and `/admin diag` show aligned three-column field grids.<br>• `/ping` is green, amber or red by network latency only (gateway, REST, voice, database).<br>• `/admin diag` is amber when YouTube is degraded, yt-dlp is outdated, or DAVE voice encryption is unavailable; green otherwise. | 1. Run `/ping`, `/about` and, as owner, `/admin diag`.<br>2. Check the column alignment and embed colors.<br>3. If possible, check `/admin diag` while yt-dlp is outdated, the resolver is degraded, or DAVE is unavailable. | `Pending Owner Run` |
